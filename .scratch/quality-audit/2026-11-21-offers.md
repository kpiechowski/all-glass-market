# Quality audit — Offers — 2026-11-21

Scope: all four layers of `app/Modules/Offers` and their tests, issues 01–14 (commits 5d68513 … 0935d36, 2026-11-20/21). Earlier audit: Catalogue, 2026-11-21 (no report file; its rules are in commit cf69349). Every Offers commit predates those rules (cf69349 landed at 16:08, after Offers 14), so this audit measures how far Offers is from them. It is not a regression test. Most Gaps below are exactly what those rules now forbid.

## What holds well
- Write path: all 28 commands are `final readonly` with primitives + one Actor. Every Filament create/edit/custom/bulk action goes through `CommandSender` + `CurrentActor::get()`. Photo paths travel in the command. No writes to Offers tables happen outside the adapters.
- Entities are plain PHP with named constructors, `reconstitute()` and intent methods. Offer, Reservation and Sale keep their refusals inside. All 63 exception keys exist. Bulk handlers (4 of 5) reuse the single-Offer entity method.
- Persistence: 5 `ReadOnlyModel`s with factories and no scopes. 4 audited models have observers and record types. Mapper round-trip tests exist. Query tests prove exclusion. Unique offer number and one current reservation are backed by constraints.
- UI reads go through `{X}Queries` (widgets, chart, tables). There is no `{!! !!}`, lang files follow the table, and every confirmation names its act.

No **Defect** (wrong result now) was found.

- Application: `?? throw` repeats an entity refusal (`SellOfferCommandHandler.php:64`, `ReleaseReservation…:44`, `ReturnSale…:36`). `AnnounceBuyersPriceChanges…:32` returns silently on an unknown type. The provider reads `OwnerJournal::KIND` from a Service (`OffersModuleServiceProvider.php:95`). `AcceptInquiry…:50,52` has `id() ?? 0`.

| P1 | **module-events knows one emission pattern (the handler).** The Offers need ("one reaction, whatever route the Offer left Active by") did not fit, so the manager accepted a deviation and "flagged it to the user", but the skill never learned a pattern. Each later worker then improvised: repository, service, listener. Q1 "rule doesn't fit + accepted deviation never became a rule". | G1, G2, App nit (Service dispatches) | **Decide the pattern** and write it into module-events.
